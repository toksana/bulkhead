# Bulkhead

A micro-frontend platform that streams high-volume OT network telemetry off the main thread and keeps critical response actions working when the rest of the system fails.

> Status: early development. Setup instructions will follow once the workspace is scaffolded.

## Scope

Bulkhead is a supervisory tool. It is not a safety system and does not replace hardware E-Stops or safety PLCs.
